殖民地应急手册 / 05

🧠 RimWorld 精神崩溃急救

发现心情临界、精神崩溃或危险行为时，先排除眼前损失，再修复诱因。

现在 · 止损

先看这个人会不会伤人或毁物

暂停并判断行为、位置和附近的武器、火源、囚犯或关键设备。

接着 · 隔离

把其他人和关键物资移开

不要一上来就把所有人围过去；先清出周围的人和易损目标。

最后 · 复盘

修正刚刚叠加的诱因

从疼痛、饥饿、睡眠、环境和近期事件中找最容易消除的一项。

处理流程 排查表 场景取舍 恢复清单

01 / 先按顺序止损

  1. 暂停，确认行为风险
  2. 移开人员与目标
  3. 保住医疗和出口
  4. 稳定后查诱因
别急着围上去：行动前先留出安全路线、医疗空间和能撤退的人手。

02 / 按症状检查

看到什么先查哪里下一步
心情持续下降疼痛、饥饿、睡眠与环境状态先处理一项可立刻恢复的负面状态
已经开始危险行为附近人员、武器、火源与关键设备先拉开距离，保护高价值或高风险目标
其他人也被拖累围观、冲突、工作和休息安排减少不必要接触，给医疗和休息留空间

03 / 场景不同，处理重点不同

🏠 在基地内 基地内：先保护容易被连带破坏的东西

厨房、医疗区、易燃仓库和狭窄走廊，优先清出无关人员。

🌲 在外面或战斗中 外面：别把救援队拖进新风险

先看敌人、天气和回程路线；需要救援时先保证有人能安全返回。

04 / 稳定后再处理长期方案

稳定后再看药物、娱乐和房间改善等长期选项。先把当前事件和最直接的负面状态处理掉，避免用一项长期方案掩盖眼前的饥饿、伤病或缺觉。

不同特质、意识形态、基因和模组可能改变处理方式，按当前殖民者界面判断。

05 / 恢复前的检查单

  • ✓ 高风险行为周围已经没有无关人员和关键物资。
  • ✓ 医疗、睡眠和食物的即时需求没有被忽略。
  • ✓ 没有为处理一个人而让基地失去防守或救援能力。
  • ✓ 已记录最先出现、最容易修复的心情诱因。

下一步：只先修最关键的一处

事情过去后，优先修复本次最早出现的那个可控问题：一张可用床、一顿饭、治疗、清洁或休息安排。一次只改一两项，再观察心情是否回升，避免在危机后把整个工作表和基地布局全推倒。

适用范围与来源

按本站 RimWorld 1.6.x 范围整理的应急流程。模组、特质、DLC 和袭击条件可能改变最佳处理方式；执行前先看当前局面。资料核对：2026-09-13，未声称游戏内实测。
