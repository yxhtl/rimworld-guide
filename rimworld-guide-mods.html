🧩 Mod 推荐

看到1.7或黄色Mod提示，先确认分支

按Ludeon 2026年10月12日公告，1.7当时在unstable测试分支，主分支仍为1.6。黄色提示可能只是版本标记未更新，不等于已证实故障，也不保证整套Mod兼容。公告说1.6/1.7存档可互读；具体Mod与旧档仍需核验。

先看实际运行版本，出现报错或进档失败时查对应Mod作者说明。下方旧推荐清单不是1.7兼容名单；框架只在所选Mod明确依赖时安装，加载顺序按作者要求核对。本站未独立测试1.7，不建议只为版本数字切换分支。

范围核查：2026-10-24。Ludeon原公告 · Harmony作者说明 · HugsLib作者说明

1. 按需安装的前置 Mod —— 先看所选 Mod 的依赖说明

Mod分类说明建议
Harmony前置框架为依赖它的 Mod 提供运行时方法补丁支持被依赖时安装，置于 Core 之前
HugsLib前置框架被部分 Mod 依赖的功能库；HugsLib 本身依赖 Harmony被依赖时安装，先于依赖它的 Mod
Vanilla Expanded Framework前置框架部分相关 Mod 使用的前置框架按所选 Mod 的依赖说明安装

2. UI 优化类 —— 不改玩法，纯体验提升

Mod功能推荐指数

💡 老手忠告： Mod 不是越多越好，每次加 Mod 前记得备份存档。Mod 数量超过 100 个时启动可能需要 5–10 分钟——别以为卡死了。

📊 Mod 加载顺序可视化

下图仅是分类示意，不是通用排序答案。未使用的框架不必安装；具体依赖、DLC与补丁顺序以对应作者说明为准。

5. 加载顺序速查 —— 示例分类，非固定顺序

  1. Harmony — 被依赖时放在 Core 之前
  2. Core — 游戏本体
  3. DLC — Royalty → Ideology → Biotech → Anomaly
  4. HugsLib — 所选 Mod 明确依赖时安装
  5. Vanilla Expanded Framework — 依具体 Mod 要求
  6. 大型前置框架 — 如 JecsTools
  7. 功能修改 — UI / 行为类
  8. 内容添加 — 新物品 / 生物 / 种族
  9. 汉化包
  10. 兼容补丁 — 按补丁作者要求，不一律垫底
先核实际依赖、支持版本与作者加载说明，不要只按类别或一张图决定整套顺序。
