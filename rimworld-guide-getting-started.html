🚀 开局生存指南

1. 选人 —— 三个人决定你的命运

开局选人是最重要的一步，比落地地点还关键。三个小人的技能组合直接决定你能不能活过头三天。


角色优先看什么开局要确认什么
建造师能稳定完成建造和基础制作没有妨碍关键劳动的工作限制
种植/烹饪能把种植和食物处理接起来至少有人能持续做饭
研究员/医生能处理医疗，或在稳定后推进研究医疗别完全无人覆盖
⚠️ 选人别只看单项高技能：更重要的是三个人合起来能建造、供食、治疗；同时留意会妨碍核心计划的工作限制与特性。
✅ 加分项：能长期稳定工作、学习效率好、心情不容易失控，都能让开局更宽松；不必为了某一个特性无限重抽。

2. 落地 —— 选对地方成功一半

  • 地形：新手选温带森林 或 干旱灌木林，别碰冰原和沙漠
  • 山地 vs 平原：山地易守难攻但会刷虫灾，平原好盖房但防守面大——新手推荐大丘陵（有山但不多）
  • 生长季：优先选生长季较长、初期有稳定食物来源的地点；越短的生长季越需要提前准备储备
  • 石头类型：优先 花岗岩 > 石灰岩 > 砂岩（花岗岩墙体最硬，= 你活得久）
  • 派系距离：别离海盗太近，友善部落近一点方便贸易

3. 前 3 天行动清单

顺序做什么为什么
第1步划种植区 + 播种适合作物先建立可持续的食物来源，再把人手接到收获、搬运和烹饪上
第2步盖一间 7×7 木屋 + 屋顶当临时仓库和睡觉用，别盖太大——后面要换石头
第3步放 3 个睡眠点 + 篝火小人睡地上不掉心情，但睡外面掉；篝火防止冻伤
第4步屠宰落地动物 + 做简易餐打包食品只能撑几天，先杀落地就有的动物
第5步划仓库（室内）+搬物资药品、食物、零件放外面会坏，赶紧搬进屋
第6步做研究桌 + 开始研究第一优先级科技：电池 → 太阳能 → 制冷（冰箱）
💡 关键认知：RimWorld 的核心循环是"吃 → 住 → 防 → 研究"。第一要务永远是食物来源稳定，第二才是盖房子。

4. 第一周：从活下来到站稳脚

  • 造屠宰台 + 灶台：简易餐吃不久，尽快做精致餐（需要灶台 + 素食 + 肉/蛋）
  • 划 3 间独立卧室：有独立房间 +5 心情，比睡大通铺强太多
  • 做石匠桌 + 切石头：木头墙不耐火（闪电一下全家烧没），尽快换石头墙
  • 造马蹄铁桩：最便宜的娱乐设施，防止小人"无聊"掉心情
  • 划垃圾储存区：尸体、石头渣子丢远点，别堆在屋里

5. 前七天的决策顺序：缺什么先补什么

开局别急着盖漂亮基地。每天先看四件事：有没有马上断粮的风险、有没有人露天睡或物资淋雨、有没有伤员和火灾、厨房到仓库的日常链路顺不顺。哪一项快出问题，就先处理哪一项。

如果你看到……先做的动作暂时别做
食物快断、作物未成熟把狩猎、采集、屠宰、烹饪和食材搬运串起来采矿、研究、全图搬运
小人或物资露天补屋顶、睡眠点和室内储存大房间和装饰
有人倒下、流血或起火切到救援、治疗、休息和灭火继续赶建筑蓝图
生存稳定、路线混乱拉近厨房、仓库、睡处和工作区同时开多个大工程
✅ 记住一句：先消除今天会死人或会断粮的风险，再做让生活更舒服的工程。它比任何固定模板都更适合新手。

⚠️ 新手最容易卡住的四件事

  1. 一开始就分工太死：人少时先保证关键活都有人能接手，稳定后再做专业分工。
  2. 只盯种地：作物还要经过搬运、屠宰或处理、烹饪，才会变成餐。
  3. 把木头当长期方案：木头用于救急，布局要留出以后换石材的余地。
  4. 研究压过生存：小人饿着、冻着或忙于救火时，研究桌救不了基地。

下一步看 工作优先级，把“谁来做”定下来；食物和温度不稳时看 温度与冷藏。
